# PxGo v0.9.1

## Windows upstream authentication

- Preserve current-user SSPI as the first authentication attempt.
- When SSPI cannot authenticate and the upstream proxy returns HTTP 407, show a
  native Windows username/password dialog and retry using the existing NTLM
  challenge-response implementation.
- Reuse accepted credentials in memory for the running process. Save them to
  Windows Credential Manager only when the user selects **Remember my credentials**
  and the upstream proxy accepts the retry.
- Serialize interactive prompts so concurrent failures do not open duplicate
  dialogs. Cancel leaves the original authentication failure in place.
- Set `PXGO_AUTH_PROMPT=0` to disable the dialog for unattended runs.
- Apply the fallback to ordinary HTTP proxy requests and HTTPS CONNECT tunnels.
