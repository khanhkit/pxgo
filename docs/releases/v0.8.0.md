# pxgo v0.8.0

Feature release adding configurable DNS/DoH resolution, verified self-update behavior, and a windowless Windows background runtime.

## Highlights

- **Configurable DNS resolution.** PxGo can use the system resolver, a custom DNS server, or DNS-over-HTTPS through one centralized resolver contract.
- **Provider-aware updates.** Package-manager installations delegate updates to their owning manager, while direct/portable installations use verified release assets with checksum/digest validation and downgrade protection.
- **Windowless Windows background mode.** Windows archives now include `pxgow.exe`, a GUI-subsystem companion that starts PxGo without a Command Prompt window while preserving `pxgo.exe` as the normal console CLI.
- **Shared configuration and tray lifecycle.** Background/startup mode reuses the same `pxgo.ini` semantics as foreground mode and exposes the canonical PxGo icon in the Windows system tray.
- **Background control behavior.** `--background`, startup, quit, and restart use the existing Guardian process tree and bounded readiness/shutdown contracts rather than adding a second supervisor.

## Release verification

This release is built from protected `main` and uses the artifact-first release pipeline. Exact candidate archives are built once, executed/verified natively before publication, then promoted unchanged with checksums, SBOMs, and provenance attestations.

Windows amd64/arm64 release archives contain both `pxgo.exe` and `pxgow.exe`, and the release verifier checks their expected subsystem/resource/version contracts before promotion.
