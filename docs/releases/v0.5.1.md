# pxgo v0.5.1

This is a maintenance release focused on distribution correctness, release usability, and clean fork-owned packaging.

## Highlights

- **Verified release artifacts before publication.** Release candidates are built once, checksum/SBOM metadata is generated once, and the exact staged archives are verified on the native release matrix before promotion.
- **Fork-owned distribution identity.** User-facing package, release, Homebrew, documentation, and module metadata now consistently use `khanhkit/pxgo`; inherited WinGet install instructions are not advertised.
- **Cleaner release publication.** Draft assets are promoted atomically and release notes are curated instead of exposing a raw commit dump.
- **Fixed tagged-commit dry-run verification.** Verifying an already-tagged release SHA now expects the existing release version instead of the temporary dry-run tag version; this removes the false Linux amd64/arm64, Windows, and macOS verifier failures seen when rechecking v0.5.0.
- **Better portable setup docs.** The README now includes a hand-written `pxgo.ini` example for users who do not want to use `--save`.
- **Support information included with downloads.** Release archives include this repository README, including the GitHub Sponsors link and support section.

## Installation

Download the archive for your platform from this release:

- Linux x86_64: `pxgo_linux_amd64.tar.gz`
- Linux ARM64: `pxgo_linux_arm64.tar.gz`
- Windows x86_64: `pxgo_windows_amd64.zip`
- Windows ARM64: `pxgo_windows_arm64.zip`
- macOS Intel: `pxgo_darwin_amd64.tar.gz`
- macOS Apple Silicon: `pxgo_darwin_arm64.tar.gz`

Verify the downloaded file with `checksums.txt` before installing.

## Configuration

You can generate a starter config:

```bash
pxgo --save --config=./pxgo.ini --proxy=proxy.company.com:8080
```

or write `pxgo.ini` manually. See the README packaged inside every archive and `docs/configuration.md` for the complete configuration reference.

## Windows authentication

On domain-joined Windows systems, pxgo can use the logged-in user's current SSPI credentials for NTLM/Negotiate upstream proxy authentication. No inherited WinGet package ID is required or advertised by this release.

## Upgrade notes

This release does not require a configuration migration from v0.5.0. Existing valid `pxgo.ini`, environment variables, and CLI flags continue to work with the documented precedence rules.
