# pxgo v0.7.1

Patch release for PAC encoding compatibility.

## Fixed

- Add strict `ascii` / `us-ascii` PAC decoding.
- Honor HTTP `Content-Type: charset=ascii` with the same priority semantics as upstream Px v0.12, including over BOM detection.
- Reject non-ASCII bytes when ASCII is explicitly selected instead of silently falling back to another decoder.

All v0.7.0 distribution, Kerberos/SPNEGO, Guardian, RLIMIT_NOFILE, Homebrew, Scoop and release-provenance behavior remains unchanged.
